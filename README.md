## 📝 How to Use

1. **Add new files** to the appropriate numbered folder, following the naming conventions (type, version, date).
2. **Keep drafts** in `02_draft`, images in `03_images`, and raw vs processed data separated under `06_unsorted_data`.
3. **Place final deliverables** in `07_submissions` when ready to submit.

## 📌 Naming Conventions

- **Folders** numbered (01–07) and lowercase with underscores.
- **Files** prefixed by purpose (e.g. `Conference_Paper`, `Survey_Raw_Data`), suffixed with version (`v1`) and date (`YYYYMMDD`).
